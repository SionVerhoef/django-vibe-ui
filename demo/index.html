Numeric field — DEC / HEX / BIN

Type a number, switch the base on the right, hit copy. Monospace + tabular figures; fires a numbase:change event. Seeded with 4660 (= 0x1234).

Value field — input/output + unit selector + copy

Widget only — the site supplies the units and conversion. Here it's a length converter your other site could reuse with any data. Change the value or either unit; the output converts. Hover the output to copy, and try the format ▾ menu (Number / value+unit / Python / MATLAB).

Accordion / FAQ

Is this the same on every site?

Yes — the structure is shared. Each site only overrides brand tokens.

Does dark mode work?

Try the MotionConvert theme — it remaps surfaces and the neutral ramp to go dark.

Do I need JavaScript?

The accordion works with zero JS (native <details> + CSS). This page also loads the optional enhancer so open AND close animate smoothly.
